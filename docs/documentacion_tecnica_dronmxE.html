1. Trazado de Misiones Lineales y Generación de Trayectoria

📏 Cálculo y Dibujo de Vuelos Lineales (Corredor)
Resuelto
Problema Diagnosticado: Al seleccionar el modo "Lineal" (o inspección de ejes/caminos), la aplicación no permitía dibujar la línea ni generar los waypoints. El sistema mantenía la regla restrictiva de polígonos cerrados de área, exigiendo un mínimo de 3 vértices antes de registrar la misión o generar la línea de vuelo.
Solución Técnica: Se desacopló la validación según el tipo de vuelo: las misiones lineales requieren un mínimo de 2 puntos (origen y destino), representándose con un L.polyline en lugar de un L.polygon. Además, se desarrolló el algoritmo de generación lineal que calcula el azimut entre cada segmento y genera disparos equidistantes basados en la velocidad de vuelo y el solape frontal fotogramétrico.
app/src/main/assets/index.html · Lógica de Dibujo Lineal 
// Umbral de puntos según tipo de misión (2 para lineal, 3 para polígono de área)
const minPoints = (AppState.mode === 'Lineal' || AppState.mode === 'Corridor') ? 2 : 3;

function generateLinealFlightWaylines(points, speed, altitude, overlapFront) {
  const waylines = [];
  for (let i = 0; i < points.length - 1; i++) {
    const p1 = points[i];
    const p2 = points[i + 1];
    const dist = window.map.distance(L.latLng(p1.lat, p1.lng), L.latLng(p2.lat, p2.lng));
    const heading = calculateBearing(p1, p2);
    
    // Subdividir el segmento en waypoints de disparo según solape frontal
    const step = calculateTriggerInterval(altitude, overlapFront);
    const steps = Math.max(1, Math.round(dist / step));
    for (let s = 0; s <= steps; s++) {
      const frac = s / steps;
      waylines.push({
        lat: p1.lat + (p2.lat - p1.lat) * frac,
        lng: p1.lng + (p2.lng - p1.lng) * frac,
        alt: altitude,
        heading: heading
      });
    }
  }
  return waylines;
}

2. Edición No Destructiva de Vértices y Puntos Medios

✏️ Manipulación Fluida de Polígonos y Líneas en el Mapa
Resuelto
Problema Diagnosticado: Al intentar arrastrar un vértice en el mapa para modificar el polígono de vuelo, los marcadores parpadeaban, se duplicaban o cancelaban el evento de arrastre (`dragend`), provocando saltos involuntarios o reseteos de coordenadas.
Solución Técnica: Se implementó un sistema de marcadores de alta fidelidad con L.circleMarker y L.divIcon reutilizables. Se añadieron marcadores de punto medio virtuales con estilo translúcido entre cada par de vértices; al arrastrar un punto medio, este se promueve automáticamente a vértice activo y recalcula inmediatamente el plan de vuelo sin necesidad de recargar la capa del mapa.
app/src/main/assets/index.html · Edición con Puntos Medios 
function renderEditingHandles() {
  clearHandles();
  const pts = AppState.points;
  if (!pts || pts.length === 0) return;

  // 1. Vértices principales con draggable: true
  pts.forEach((pt, idx) => {
    const m = L.marker([pt.lat, pt.lng], { draggable: true, icon: vertexIcon }).addTo(editingLayer);
    m.on('drag', (e) => {
      AppState.points[idx] = { lat: e.latlng.lat, lng: e.latlng.lng };
      updatePreviewShape();
    });
    m.on('dragend', () => {
      recalculateMission();
      renderEditingHandles();
    });
  });

  // 2. Marcadores virtuales de punto medio para añadir vértices dinámicos
  for (let i = 0; i < (AppState.mode === 'Area' ? pts.length : pts.length - 1); i++) {
    const nextIdx = (i + 1) % pts.length;
    const midLat = (pts[i].lat + pts[nextIdx].lat) / 2;
    const midLng = (pts[i].lng + pts[nextIdx].lng) / 2;
    const midM = L.marker([midLat, midLng], { draggable: true, icon: midPointIcon, opacity: 0.6 }).addTo(editingLayer);
    midM.on('dragstart', () => {
      pts.splice(i + 1, 0, { lat: midLat, lng: midLng });
    });
    midM.on('dragend', () => {
      recalculateMission();
      renderEditingHandles();
    });
  }
}

3. Activación Inteligente del Candado de Protección

🔒 Bloqueo Únicamente al Regresar a la Vista del Mapa
Resuelto
Problema Diagnosticado: Al crear una nueva misión de vuelo, la aplicación abría automáticamente el panel de configuración de parámetros, pero a los pocos segundos un temporizador de guardado automático activaba el candado (`locked = true`). Esto bloqueaba la misión e impedía seguir modificando parámetros fotogramétricos o ajustar la geometría.
Solución Técnica: Se desvinculó el estado de bloqueo de los temporizadores internos de guardado. Se fijó la regla de que el candado sólo se activa en el momento exacto en que el usuario presiona "Volver al Mapa" (`switchToView('map')`). De este modo, el operador puede configurar altura, velocidad, solape y resolución sin ninguna traba.
app/src/main/assets/index.html · Regla de Bloqueo al Salir 
function switchToView(viewName) {
  if (viewName === 'map') {
    // Bloqueo automático inteligente: SOLO se activa al volver al mapa
    if (AppState.currentMissionIdx !== null && AppState.savedMissions[AppState.currentMissionIdx]) {
      const curM = AppState.savedMissions[AppState.currentMissionIdx];
      const mMin = (curM.mode === 'Lineal' || curM.mode === 'Corridor') ? 2 : 3;
      if (curM.points && curM.points.length >= mMin) {
        curM.locked = true; // Proteger contra toques accidentales en el mapa
      }
    }
  }
  document.querySelectorAll('.view-panel').forEach(p => p.classList.remove('active'));
  document.getElementById(`view-${viewName}`).classList.add('active');
  renderMissionList();
}

5. Sobreescritura Forzada e Inyección en DJI RC 2 (MTP y Memoria)

🎮 Inyección Segura en Ranuras de Waypoints de DJI Fly
Resuelto
Problema Diagnosticado: Al intentar sobreescribir una misión en el control RC 2 desde la pestaña "Control RC 2 (MTP)", el proceso no finalizaba o el archivo no se reemplazaba debido a dos motivos: 1. Las funciones JS de sincronización estaban atrapadas dentro de un script de Leaflet no globalizado. 2. La coincidencia del nombre del archivo fallaba cuando el usuario omitía o incluía la extensión `.kmz`.
Solución Técnica: Se independizó el bloque de scripts MTP y se construyó en Java el método resolveTargetKmzFile() con algoritmo de búsqueda de triple capa (ruta absoluta directa, coincidencia con/sin extensión `.kmz`, y escaneo recursivo en /Download/dronmxE, /Documents y caché). Adicionalmente, se ejecuta escritura directa en las rutas de waypoint de DJI Fly con comandos de respaldo Linux cp -f y chmod 666 para garantizar que DJI Fly cargue la misión actualizada al instante.
app/src/main/java/com/dronmxe/mtpbridge/MainActivity.java · Resolución de Archivo 
private File resolveTargetKmzFile(String localFileNameOrPath) {
    if (localFileNameOrPath == null || localFileNameOrPath.trim().isEmpty()) return null;
    String clean = localFileNameOrPath.trim();

    // 1. Comprobación directa de ruta en disco
    File direct = new File(clean);
    if (direct.exists() && direct.isFile()) return direct;

    if (!clean.endsWith(".kmz") && !clean.endsWith(".kml")) {
        File directKmz = new File(clean + ".kmz");
        if (directKmz.exists() && directKmz.isFile()) return directKmz;
    }

    // 2. Búsqueda en lista de misiones escaneadas
    synchronized (availableKmzFiles) {
        for (File f : availableKmzFiles) {
            if (f.getAbsolutePath().equalsIgnoreCase(clean) || 
                f.getName().equalsIgnoreCase(clean) || 
                f.getName().equalsIgnoreCase(clean + ".kmz")) {
                return f;
            }
        }
    }

    // 3. Fallback exhaustivo en directorios públicos y carpetas DJI
    File dl = Environment.getExternalStoragePublicDirectory(Environment.DIRECTORY_DOWNLOADS);
    String nameWithKmz = clean.endsWith(".kmz") ? clean : (clean + ".kmz");
    File[] candidates = new File[]{
        new File(dl, clean),
        new File(dl, nameWithKmz),
        new File(new File(dl, "dronmxE"), nameWithKmz),
        new File("/sdcard/Download/" + nameWithKmz)
    };
    for (File c : candidates) {
        if (c.exists() && c.isFile()) return c;
    }
    return null;
}

6. Estructura de Empaquetado KMZ Universal (Google Earth + DJI WPML)

📦 Doble Compatibilidad en un Mismo Archivo KMZ
Resuelto
Arquitectura del Contenedor KMZ: Un archivo KMZ convencional sólo incluye doc.kml para visores geográficos, mientras que un archivo DJI WPML sólo incluye la subcarpeta wpmz/. dronmxE genera un archivo híbrido universal que contiene ambos formatos simultáneamente:
Ruta Interna en el Archivo .KMZ Propósito Consumidor
/doc.kml Representación 3D del polígono y líneas con altitud relativa al suelo Google Earth, ArcGIS Pro, QGIS, Global Mapper
/wpmz/template.kml Definición del tipo de plantilla, dron (Air 3S = 90) y velocidad global DJI Fly App / DJI Pilot 2
/wpmz/waylines.wpml Waypoints exactos, acciones de disparo fotográfico, ángulos de gimbal pitch y headings Piloto Automático DJI RC 2

8. Puente Nativo Android (Java BridgeInterface)

🌉 Integración Nativa de Portapapeles, WhatsApp y Hápticos
Resuelto
Comunicación Bidireccional Segura: Para evitar restricciones de seguridad de los WebViews de Android al acceder a navigator.clipboard o al intentar abrir enlaces externos mailto: o whatsapp://, se implementaron métodos nativos en BridgeInterface:
app/src/main/java/com/dronmxe/mtpbridge/MainActivity.java · Métodos Bridge 
@JavascriptInterface
public void copyToClipboard(String text, String label) {
    runOnUiThread(() -> {
        try {
            ClipboardManager clipboard = (ClipboardManager) getSystemService(Context.CLIPBOARD_SERVICE);
            ClipData clip = ClipData.newPlainText(label != null ? label : "dronmxE", text);
            if (clipboard != null) {
                clipboard.setPrimaryClip(clip);
                triggerHaptic();
                showToast("📋 " + (label != null ? label : "Dato") + " copiado al portapapeles");
            }
        } catch (Exception e) {
            showToast("Error al copiar: " + e.getMessage());
        }
    });
}

@JavascriptInterface
public void openWhatsApp(String phone, String message) {
    runOnUiThread(() -> {
        try {
            String clean = phone.replaceAll("[^0-9]", "");
            if (clean.length() == 10) clean = "52" + clean;
            String url = "https://api.whatsapp.com/send?phone=" + clean + "&text=" + Uri.encode(message);
            Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(url));
            intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
            startActivity(intent);
        } catch (Exception e) {
            showToast("No se pudo abrir WhatsApp: " + e.getMessage());
        }
    });
}
